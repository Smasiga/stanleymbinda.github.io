# Aeternum Brand Canon (v2 — 2026-10-24)

The rules that keep this site honest. Change the site only in ways that keep every line below true.

## 0. The honesty rule (highest law here)
No company exists. "Aeternum" names the body of work — ten architectures under one independent practice — not a registered entity. Never write "Ltd", "Inc", "founded [company]", "incorporated", or any institutional claim (vault-as-legal-entity, trusts, succession, partnerships) unless a real legal event has occurred AND counsel has cleared the wording. When the legal business name arrives, it gets its own dated entry. Nothing is backdated, ever.

## 1. Identity (canonical, no variants)
- Human: **Stanley Masiga Mbinda**, independent architect and builder, Nairobi.
- `Æ` lives ONLY in the SVG logotype. All text — titles, meta, body, footers — spells **Aeternum** (the work's name, never a company claim).
- Handles: `Smasiga` = code (GitHub), `stanleymbinda.com` = home, LinkedIn = professional. Every profile links the other two.

## 2. Numbers (dated or absent)
- **Ten** founding architectures (I–X, fixed names — see index grid). Never "five" except inside dated historical entries (milestones), which stay verbatim.
- Status vocabulary, site-wide: **Deployed** (live + linked), **In engineering** (real, evidence on request). No other status words.
- Proof beats prose: every claim links live evidence, a dated milestone, or a case study. New claims without evidence do not ship.

## 3. Voice
- Plain, sourced, no adjectives it can't prove. Interpretive-age framing is the register; hype is forbidden.
- No theater, ever: no fake endpoints, no simulated checkers, no queued-into-the-void forms. Contact = direct email + stated 2-business-day response time.
- Founder signs lab notes personally. The funnel postmortem (Entry 002) stays published — owning failure is the brand.

## 4. Design system
- `themes.css` = tokens + type + motion discipline + 11 per-page themes. `app.css` = components. Same class hooks everywhere; never rename a shared class.
- Prose is serif at reading size. Mono is for labels/data/code only. Display stays Bebas.
- No perpetual motion (no shimmer/sweep/pulse loops). Interaction may transition; content never animates in. `prefers-reduced-motion` kills everything.
- Every class used in HTML must exist in CSS (see validate script). Every internal link must resolve. Sitemap lists every indexable page; lastmod = content era (today only for files actually rewritten).
