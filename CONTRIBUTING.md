# Contributing to stanleymbinda.github.io

This is a personal portfolio website. While contributions are appreciated, please note the following:

## Code Changes

Contributions are welcome for:
- Bug fixes
- Performance improvements
- Accessibility enhancements
- Documentation improvements

## How to Contribute

1. **Fork** the repository
2. **Create a branch** (`git checkout -b improvement/amazing-feature`)
3. **Make your changes** with clear commit messages
4. **Push** to your fork
5. **Submit a Pull Request** with a clear description

## Guidelines

- Maintain the existing code style and aesthetic
- Ensure responsiveness across all devices
- Test in modern browsers (Chrome, Firefox, Safari, Edge)
- Update documentation if you change functionality
- Keep commits atomic and descriptive

## Design Philosophy

This site embodies a specific design language:
- **Dark + Gold aesthetic** for sophistication and permanence
- **Minimalist interaction** with purposeful animations
- **Performance-first** — no heavy frameworks
- **Accessibility** — semantic HTML, clear contrast

Please respect this vision when proposing changes.

## Intellectual Property

The architectural concepts, business logic, and institutional frameworks mentioned on this site are proprietary. Contributions to the website code do not grant access to these protected works.
