HCIP

Holistic Code Intelligence Platform · The Skeleton · The Nervous System · The Soul

A code-intelligence platform that parses repositories into a three-layer knowledge graph — skeleton, nervous system, soul — joined by content-hashed entity IDs. Six engines (parsing, soul, analysis, simulation, generation, recommendation) run over Kafka, Neo4j, Postgres, and ClickHouse, with IDE plugins and its own query language.

Working system — multi-service codebase with layered tests. Not publicly serving.
