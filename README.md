## Deploy & Custom Domain

This site is hosted on GitHub Pages with a custom domain.

**To point your domain:**
1. Add `CNAME` file with your domain (already configured: `stanleymbinda.com`)
2. Update DNS records to point to GitHub Pages nameservers
3. Enable HTTPS in GitHub repository settings
